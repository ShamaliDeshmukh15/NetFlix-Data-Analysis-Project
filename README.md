# Netflix Movies Data Analysis

## Project Overview
Analyzed Netflix movie data using Python to identify trends in genres, ratings, popularity, and movie releases.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Activities
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Data Visualization
- Movie Genre and Rating Analysis

## Project Files
- Jupyter Notebook
- Netflix Movies Dataset
